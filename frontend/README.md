# Student Skill Exchange Frontend

Static HTML, CSS, and JavaScript frontend for the Student Skill Exchange platform.

## Run locally

1. Start the [backend API](https://github.com/24eg105r33-wq/backend) and its MySQL database.
2. Open `index.html` with the VS Code Live Server extension.
3. Visit <http://127.0.0.1:5500> or <http://localhost:5500>.

The frontend calls the API at `http://localhost:8080/api`.
